The LineSensor8 is a high-precision line-following sensor designed specifically for WRO robotics competitions. Featuring <span style="color: red;">8-channel infrared detection</span> and an <span style="color: red;">intelligent anti-interference algorithm</span>, it effectively reduces false detections caused by colorful patterns on complex competition fields. It supports one-button calibration in just 5 seconds and provides high-resolution line position, line width, and sensor status data. Combined with PID control, it enables smoother, more stable, and more accurate line-following performance.

## Before You Begin

1. Make sure your controller and MBC S8 Line-Following Sensor versions match.
2. Connect your MBC S8 Line-Following Sensor to the controller using a cable.
3. After powering on, the green heartbeat indicator (near the connector) will begin flashing.

## Calibration and Normalization

1. Press the calibration button
    - Hold down the calibration button on the sensor for 0.5 seconds until the 🟢 green calibration indicator (near the calibration button) stays illuminated.
2. Start scanning (5 seconds)
    - Move the sensor back and forth across the black lines and white areas of the field.
    - Scan the darkest and brightest areas.
    - Keep the sensor 0.5–1.2 cm above the ground.
3. Wait for completion
    - Wait until the 🟢 green calibration indicator turns off. Calibration is now complete.
    - Calibration values are saved automatically, so recalibration is not required the next time the sensor starts (provided the environmental conditions remain the same).

## Hardware Indicator Reference

| Indicator | Illustration | Status Description |
| --- | --- | --- |
| 🟢 Green Heartbeat Indicator (near the connector) |  | Flashes once per second, indicating that the sensor is powered correctly and the system is operating normally. |
| 🟢 Green Calibration Indicator (near the calibration button) |  | After holding the button for 0.5 seconds, this green indicator remains illuminated for 5 seconds while calibration is in progress. It turns off when calibration is successfully completed. |
| 🔴 Red Indicator (communication debug LED) |  | A steady light indicates a communication failure with the main controller. Check that the connection cable is securely inserted, or try a different controller port or cable for troubleshooting. |
| 🔘 One-Button Calibration Button |  | Press and hold for 0.5 seconds, then release to enter calibration mode (the green calibration indicator remains illuminated for 5 seconds). |
| 💡 Onboard 8-Channel Status LED Array |  | An illuminated LED indicates that the corresponding channel has detected a black line. |
