循行者 16 路感應器 (LineSensor16) 是專為 WRO 機器人競賽設計的高精度循線感應器，搭載 <span style="color: red;">16 通道紅外線偵測</span> 與 <span style="color: red;">智慧抗干擾演算法</span>，能有效降低複雜賽道中彩色圖案造成的誤判。支援 5 秒一鍵校準，並提供高解析度線條位置、線寬及感測器狀態數據，搭配 PID 控制可實現更平順、穩定且精準的循線表現。

## 開始之前

1. 確認你的控制器與 MBC S16 巡跡板版本是否相同。
2. 透過電線連接你的 MBC S16 巡跡板與控制器。
3. 通電後感應器上的綠色心跳指示燈 (靠近插座) 會開始閃爍。

## 校正與正規化
1. 按下校準按鈕
    - 按住感應器上的校準按鈕 0.5 秒，直到 🟢 綠色校準指示燈 (靠近校準按鈕) 保持亮起。
2. 開始掃描 (5 秒)
    - 將感應器在場地黑色與白色區塊上來回移動。
    - 掃描最黑和最白的區域
    - 感應器距離地面 0.5 ~ 1.2 公分。
3. 等待完成
    - 等待 🟢 綠色校準指示燈熄滅，校準完成。
    - 校準數值會自動儲存，下次啟動不用重新校正 (相同環境狀況下)。


## 硬體指示燈說明
| 燈號 | 狀態說明 |
| --- | --- |
| 🟢 綠色心跳指示燈 (靠近插座) | 每秒閃爍一次，表示感應器供電正常且系統正常運作中。 |
| 🟢 綠色校準指示燈 (靠近校準按鈕) | 按住按鈕 0.5 秒後此綠燈會持續亮起 5 秒，代表校準進行中；熄滅表示校準順利完成。 |
| 🔴 紅色指示燈 (通訊除錯燈) | 長亮表示與主控板通訊失敗。請檢查連接線是否插緊，或更換主機連接埠 / 連接線進行交叉測試。 |
| 🔘 一鍵校準按鈕 | 按住 0.5 秒放開，進入校準模式 (綠色校準指示燈持續亮起 5 秒)。 |
| 💡 板載 16 路狀態 LED 陣列 | 燈亮表示該通道偵測到線。 |
