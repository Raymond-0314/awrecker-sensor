# 使用教學

## 01 / 環境準備

### ✔ 請確認控制器、感應器與程式環境

| 要求 | 符合本教學頁面的種類 |
| --- | --- |
| 控制器 | Arduino UNO / Nano / UNO R4 / ESP32 |
| 感應器 | MBC 神攝手視覺感應器 (通用 I²C 版) |
| 程式語言 | Arduino IDE (C++) |

### ✔ 事前準備

1. 啟動你的開發板與 Arduino IDE。
2. 確認主機、相機與程式環境運作正常。
3. 設定感應器模式，確認與程式設定模式相同。

::: warning ⚠️ 接線前先確認
v1 的資料格式已定案，Arduino 實機驗證尚未完成。相機端 SDA = IO3、SCL = IO1 仍為暫定。請核對實際版本與邏輯電位後接線。
:::

| 相機 | UNO / Nano | UNO R4 / ESP32 |
| --- | --- | --- |
| 5V | 5V | 確認合適的 5V 電源 |
| GND | GND | GND |
| SDA | A4 | 主板 SDA |
| SCL | A5 | 主板 SCL |

## 02 / 函數與功能說明

::: info ℹ️ 補充資訊
- 使用通用 I²C 韌體，預設裝置位址為 `0x4C`。`0x10` 等數字是相機內的資料欄位編號，不是 I²C 裝置位址。切換相機模式使用 E0 命令，取樣點位置使用 E1 命令。
- I²C 讀取時先寫入起始欄位，等 2 ms，再讀取低位在前的 int16；每次最多讀 16 個值。
:::

::: warning ⚠️ 注意
- 一次只能使用一種相機子模式，請確認相機 Mode ID 與程式設定相同。
- 不同模式共用相同讀取指令，回傳內容須依該模式的表格解碼。
:::

## 03 / 範例程式

先在相機教目標色 1。程式在 setup() 傳送 E0 [1, 3]，選擇 Mode ID 13 (顏色追蹤 - ③ 標準)。序列監控設 115200 baud，程式分 5 批讀完模式 13 的 65 個欄位，先顯示找到的總色數，再依序顯示各已找到顏色的 X、Y、面積與數量。下方的列印迴圈只是依序顯示陣列內容；每個欄位的對應都已完整列在模式 13 的表格。

```cpp
#include <Wire.h>
const uint8_t CAMERA = 0x4C;

bool readCamera(uint8_t first, uint8_t count, int16_t *values) {
  if (count == 0 || count > 16) return false;
  Wire.beginTransmission(CAMERA);
  Wire.write(first);
  if (Wire.endTransmission() != 0) return false;
  delay(2);
  uint8_t bytes = 2 * count;
  if (Wire.requestFrom(CAMERA, bytes) != bytes) return false;
  for (uint8_t i = 0; i < count; ++i) {
    uint16_t low = Wire.read();
    uint16_t high = Wire.read();
    uint16_t raw = low | (high << 8);
    values[i] = static_cast<int16_t>(raw);
  }
  return true;
}

bool setCameraMode(uint8_t mode, uint8_t submode) {
  Wire.beginTransmission(CAMERA);
  Wire.write(0xE0);
  Wire.write(mode);
  Wire.write(submode);
  return Wire.endTransmission() == 0;
}

void setup() {
  Serial.begin(115200);
  Wire.begin();
  if (!setCameraMode(1, 3)) {
    Serial.println("Camera mode command failed");
  }
  delay(100);
}

void loop() {
  int16_t mode, values[65];
  if (!readCamera(0x01, 1, &mode)) {
    Serial.println("Check camera wiring and address");
  } else if (mode != 13) {
    Serial.println("Select camera mode 13");
  } else if (!readCamera(0x10, 16, values) ||
             !readCamera(0x20, 16, values + 16) ||
             !readCamera(0x30, 16, values + 32) ||
             !readCamera(0x40, 16, values + 48) ||
             !readCamera(0x50, 1, values + 64)) {
    Serial.println("Camera data read failed");
  } else if (values[0] == -32768) {
    Serial.println("Target data unavailable");
  } else {
    Serial.print("Colors found: ");
    Serial.println(values[64]);
    for (uint8_t color = 1; color <= 16; ++color) {
      uint8_t offset = (color - 1) * 4;
      if (values[offset] == 0) continue;
      Serial.print("Color ");
      Serial.print(color);
      Serial.print(": ");
      for (uint8_t field = 0; field < 4; ++field) {
        Serial.print(values[offset + field]);
        Serial.print(' ');
      }
      Serial.println();
    }
  }
  delay(100);
}
```

### ✔ 常見問題

- 沒有回應：確認韌體、共地、SDA / SCL、位址。
- 讀到 -32768：先確認 0x01 的模式，再查欄位表。

### ✔ 寫入命令

| 傳送 bytes | 用途 |
| --- | --- |
| 0xE0, 模式, 子選項 | 切換並保存模式。例如 0xE0, 5, 2 選物體詳細。 |
| 0xE1, 點號, X, Y | 保存取樣位置。接受點號 1 ~ 20，X = 0 ~ 159、Y = 0 ~ 119。讀值提供 16 點。 |
| 0xF8, 新位址, 新位址逐位元取反 | 更換 I²C 位址。 |
| 0xEF, 0xA5 | 重新開機。 |
