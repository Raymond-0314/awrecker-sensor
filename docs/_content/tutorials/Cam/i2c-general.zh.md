# 使用教學

## 01 / 環境準備

### ✔ 請確認控制器、感應器與程式環境

| 要求 | 符合本教學頁面的種類 |
| --- | --- |
| 控制器 | Arduino UNO / Nano / UNO R4 / ESP32 |
| 感應器 | MBC 神攝手視覺感應器 (通用 I²C 版) |
| 程式語言 | Arduino IDE (C++) |

### ✔ 事前準備

1. 啟動你的開發板與 Arduino IDE。
2. 確認主機、相機與程式環境運作正常。
3. 設定感應器模式，確認與程式設定模式相同。

::: warning ⚠️ 接線前先確認
v1 的資料格式已定案，Arduino 實機驗證尚未完成。相機端 SDA = IO3、SCL = IO1 仍為暫定。請核對實際版本與邏輯電位後接線。
:::

| 相機 | UNO / Nano | UNO R4 / ESP32 |
| --- | --- | --- |
| 5V | 5V | 確認合適的 5V 電源 |
| GND | GND | GND |
| SDA | A4 | 主板 SDA |
| SCL | A5 | 主板 SCL |

## 02 / 函數與功能說明

::: info ℹ️ 補充資訊
- 使用通用 I²C 韌體，預設位址 0x4C。下表的 values 索引對應範例 readCamera() 回傳的 int16 陣列；0x10 是第一筆資料的起始欄位。切換模式使用 E0 命令，取色點位置使用 E1 命令。
- 表格的 values 是 readCamera() 讀出的 int16 陣列，0x10 等數字是資料欄位編號；每筆資料以低位在前的兩個 byte 傳送。負數循線值保留原符號，不要加減 100。
- 每次先寫起始欄位，等 2 ms，再讀取低位在前的 int16；一次最多讀 16 個值。`-32768` 表示目前模式沒有該欄位。
- 面積、飽和度、明度、線寬與路口距離以百分比表示，數值範圍不另外加百分號。
:::

::: warning ⚠️ 注意
- 一次只能使用一種相機子模式，請確認相機 Mode ID 與程式設定相同。
- 不同模式共用相同讀取指令，回傳內容須依該模式的表格解碼。
:::

<CamModeSection mode="11" title="顏色追蹤 - ① 最多色">

`I2C 可讀：16 色位置`

::: info ℹ️ 補充資訊
- 座標使用 `160 × 120` 像素，X 向右、Y 向下增加。若 X 回傳 0 表示未找到。
- 表格列出第 1 筆，共 16 筆。第 i 筆起始欄位 = `0x10 + 2 × (i - 1)`；每筆讀 2 個 int16，values 的索引每次從 0 開始。
- 總數另外讀取：先宣告 `int16_t total;`，再呼叫 `readCamera(0x30, 1, &total)`。
- 主要欄位使用 `readCamera(0x10, 2, values)` 讀取；共用讀取函式在第 03 節。
:::

| 官方圖形指令 / 讀取位置 | 功能 | 數值意義說明 |
| --- | --- | --- |
| `values[0]`<br>`0x10` | 顏色 1 的 X | `0 ~ 159`<br>• 顏色 1 的 X = 讀取數值。 |
| `values[1]`<br>`0x11` | 顏色 1 的 Y | `0 ~ 119`<br>• 顏色 1 的 Y = 讀取數值。 |
| `0x30` (另讀) | 找到顏色的色數 | `0 ~ 16`<br>• 找到顏色的色數 = 讀取數值。<br>• 這是找到的總色數；本模式可讀到幾色位置，請看上方數量說明。 |

#### 模式二：指定座標取色

<CamModeSection mode="21" title="座標取色 - ① 色相">

`I2C 可讀：16 點色相`

::: info ℹ️ 補充資訊

## 03 / 範例程式

先在相機教目標色 1。程式在 setup() 傳送 E0 [1, 3]，選擇 Mode ID 13 (顏色追蹤 - ③ 標準)。序列監控設 115200 baud，輸出依序為 X、Y、面積 %、數量。

```cpp
#include <Wire.h>
const uint8_t CAMERA = 0x4C;

bool readCamera(uint8_t first, uint8_t count, int16_t *values) {
  if (count == 0 || count > 16) return false;
  Wire.beginTransmission(CAMERA);
  Wire.write(first);
  if (Wire.endTransmission() != 0) return false;
  delay(2);
  uint8_t bytes = 2 * count;
  if (Wire.requestFrom(CAMERA, bytes) != bytes) return false;
  for (uint8_t i = 0; i < count; ++i) {
    uint16_t low = Wire.read();
    uint16_t high = Wire.read();
    uint16_t raw = low | (high << 8);
    values[i] = static_cast<int16_t>(raw);
  }
  return true;
}

bool setCameraMode(uint8_t mode, uint8_t submode) {
  Wire.beginTransmission(CAMERA);
  Wire.write(0xE0);
  Wire.write(mode);
  Wire.write(submode);
  return Wire.endTransmission() == 0;
}

void setup() {
  Serial.begin(115200);
  Wire.begin();
  if (!setCameraMode(1, 3)) {
    Serial.println("Camera mode command failed");
  }
  delay(100);
}

void loop() {
  int16_t mode, target[4];
  if (!readCamera(0x01, 1, &mode)) {
    Serial.println("Check camera wiring and address");
  } else if (mode != 13) {
    Serial.println("Select camera mode 13");
  } else if (!readCamera(0x10, 4, target) || target[0] == -32768) {
    Serial.println("Target data unavailable");
  } else if (target[0] == 0) {
    Serial.println("No target");
  } else {
    for (uint8_t i = 0; i < 4; ++i) {
      Serial.print(target[i]);
      Serial.print(' ');
    }
    Serial.println();
  }
  delay(100);
}
```

### ✔ 常見問題

- 沒有回應：確認韌體、共地、SDA / SCL、位址。
- 讀到 -32768：先確認 0x01 的模式，再查欄位表。

### ✔ 寫入命令

| 傳送 bytes | 用途 |
| --- | --- |
| 0xE0, 模式, 子選項 | 切換並保存模式。例如 0xE0, 5, 2 選物體詳細。 |
| 0xE1, 點號, X, Y | 保存取樣位置。接受點號 1 ~ 20，X = 0 ~ 159、Y = 0 ~ 119。讀值提供 16 點。 |
| 0xF8, 新位址, 新位址逐位元取反 | 更換 I²C 位址。 |
| 0xEF, 0xA5 | 重新開機。 |
