## 01 / 環境準備

### ✔ 請確認控制器、感應器與程式環境

| 要求 | 符合本教學頁面的種類 |
| --- | --- |
| 控制器 | LEGO® MINDSTORMS® EV3 |
| 感應器 | MBC 神攝手視覺感應器 (EV3 版) |
| 程式語言 | Pybricks Blocks |

### ✔ 事前準備

1. 啟動你的機器人與 Pybricks Blocks。
2. 確認主機、相機與程式環境運作正常。
3. 設定感應器模式，確認與程式設定模式相同。

## 02 / 函數與功能說明

::: info ℹ️ 補充資訊
神攝手會顯示為紅外線感應器。近接 (0) 回傳相機 modeID；信標 (1) 有八格、遙控 (2) 有四格。模式在相機上設定，EV3 只讀取資料。
:::

## 03 / 範例程式

### ✔ 讀取目標色 1 的位置與面積

先教目標色 1，再把相機切到 13 (顏色追蹤 - ③ 標準)。

1. 啟動時先讀一次近接，確認是 13。
2. 在迴圈中讀信標通道 1。方向存為位置，距離存為面積。
3. 若位置是 0，顯示「未找到」。否則以整數除法與取餘數拆出 X、Y，再顯示面積。例：43、18 代表 X=4、Y=3、面積 18%。
