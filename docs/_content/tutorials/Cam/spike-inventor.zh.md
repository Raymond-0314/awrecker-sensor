#### 模式二：指定座標取色

<CamModeSection mode="21" title="座標取色 - ① 色相">

最多讀取 4 個取樣點的色相，精度依下方欄位格式。

| 積木欄位 | 回傳值 |
| --- | --- |
| 顏色 | 0 |
| 反射光 | floor((Hue4+1)÷2) |
| 原始紅 | Hue1 |
| 原始綠 | Hue2 |
| 原始藍 | Hue3 |

第 4 點色相除以 2 傳送，讀值乘以 2 為近似色相。

</CamModeSection>

<CamModeSection mode="22" title="座標取色 - ② 色相＋飽和">

最多讀取 2 個取樣點的色相與飽和，精度依下方欄位格式。

| 積木欄位 | 回傳值 |
| --- | --- |
| 顏色 | 0 |
| 反射光 | Sat2 |
| 原始紅 | Hue1 |
| 原始綠 | Sat1 |
| 原始藍 | Hue2 |

</CamModeSection>

<CamModeSection mode="23" title="座標取色 - ③ 色相＋飽和＋明度">

最多讀取 2 個取樣點的色相、飽和與明度，精度依下方欄位格式。

| 積木欄位 | 回傳值 |
| --- | --- |
| 顏色 | 0 |
| 反射光 | floor(Sat2÷10)×10+floor(Val2÷10) |
| 原始紅 | Hue1 |
| 原始綠 | floor(Sat1÷10)×10+floor(Val1÷10) |
| 原始藍 | Hue2 |

飽和與明度以十位數合併。讀值整除 10 和取餘數後，各乘以 10 為近似值。

</CamModeSection>

## 03 / 範例程式

### ✔ 家用版積木讀取目標色 2

使用 Robot Inventor 主機與家用版 App，將相機接到 C 埠。在相機上教目標色 1、2，再選 modeID 13 (顏色追蹤 - ③ 標準)。

1. 新增重複執行迴圈，放入 C 埠顏色感應器的「原始紅」數值積木，將讀值存為 position。
2. 使用數學積木計算 X＝向下取整(position÷10)，Y＝position 除以 10 的餘數。
3. position＝0 時顯示「未找到」；否則顯示 X、Y。例：63 代表 X＝6、Y＝3。
4. 等待 0.1 秒後重複。移動目標，確認 X 向右增加、Y 向下增加；目標移出畫面時讀值應回到 0。

家用版的原始紅位置以 10 拆解。改用家用版 Python 的 device.get() 時，請依[站內 SPIKE App 教學](./spike-app.md)的教育版欄位排列解讀。
