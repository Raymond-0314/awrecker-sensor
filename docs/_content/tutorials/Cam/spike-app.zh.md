# 使用教學

## 01 / 環境準備

### ✔ 請確認控制器、感應器與程式環境

| 要求 | 符合本教學頁面的種類 |
| --- | --- |
| 控制器 | LEGO® Education SPIKE™ Prime Set |
| 感應器 | MBC 神攝手視覺感應器（SPIKE 版） |
| 程式語言 | LEGO Education SPIKE 3 App |

### ✔ 事前準備

1. 將神攝手接到主機 A～F 任一連接埠。下方範例使用 C 埠，由主機供電。
2. 連線後確認相機螢幕左上角的主機名稱顯示綠色。若為紅色，請檢查接線或換一個埠。
3. 在相機 `MODE` 選單選擇「顏色追蹤 ③ 標準」，將目標放在畫面中央，按 `OK` 教色，並確認即時畫面已框出目標。

## 02 / 函數與功能說明

::: info ℹ️ 補充資訊
官方 App 會將神攝手顯示為「顏色感應器」。在「更多感應器」使用數值型積木讀值。 相機模式由機身切換。
:::

### ✔ 顏色追蹤 ③ 標準

積木最多讀取 4 色的位置，位置以 16×12 格表示。Y 越小越靠近畫面上緣，X 為 0 表示未偵測到目標。

| 官方圖形指令 | 功能 | 數值意義說明 |
| --- | --- | --- |
| *［圖片待補｜顏色積木］* | 色 1 X | 直接讀取 `1–16` |
| *［圖片待補｜反射光積木］* | 色 1 Y | 直接讀取 `1–12` |
| *［圖片待補｜原始紅積木］* | 色 2 X / Y | 除以 256 的餘數為 X，整除 256 得 Y。 |
| *［圖片待補｜原始綠積木］* | 色 3 X / Y | 除以 256 的餘數為 X，整除 256 得 Y。 |
| *［圖片待補｜原始藍積木］* | 色 4 X / Y | 除以 256 的餘數為 X，整除 256 得 Y。 |

顏色追蹤 ①／② 最多讀 7 色，座標改用 8×6 格。「顏色」是找到的色數，「反射光」是色 1 的 X×10＋Y。原始紅、綠、藍各含兩色，整除 100 與取餘數後，再各自以 10 拆出 X、Y。

::: warning ⚠️ 注意
教育版的「顏色」積木會把相機送出的 `5` 轉成 `6`，因此這個欄位無法區分兩者。若使用教育版 Python，可用 `device.data(port.C)[0]` 讀原始值。
:::

### ✔ 物體偵測

相機依物體大小排序。代碼整除 10 得目標色號，除以 10 的餘數得形狀。例如 `13` 代表目標色 1 的三角形，`0` 表示沒有物體。表中以 X×10＋Y 儲存的位置是 8×6 格。

| 積木 | ① 物體清單（51） | ② 物體詳細（52） |
| --- | --- | --- |
| 顏色 | 物體數 | 物體 1 代碼 |
| 反射光 | 物體 1 代碼 | 物體 1 面積 % |
| 原始紅 | 物體 1 位置（X×10＋Y） | 低位為 X，高位為 Y（以 256 拆解） |
| 原始綠 | 整除 100 得物體 2 代碼，餘數為位置 | 低位為寬，高位為高（以 256 拆解） |
| 原始藍 | 同原始綠，對應物體 3 | 低位為物體 2 代碼，高位為面積 %（以 256 拆解） |

### ✔ 其他相機模式與可讀範圍

| 相機模式 | 可讀資料 |
| --- | --- |
| 11 追蹤① 最多色 | 積木讀 7 色位置，Python 實際可讀 13 色 |
| 12 追蹤② 多色 | 積木讀 7 色位置，額外欄位含數量 |
| 13 追蹤③ 標準 | 積木讀 4 色位置，面積須看額外欄位 |
| 14 追蹤④ 精細 | 2 色位置和寬高，原始綠／藍為色 1／2 寬高 |
| 21 取色① 色相 | 原始紅／綠／藍各裝兩點色相，共 6 點 |
| 22 取色② 色相＋飽和 | 原始 RGB 依序為 S1–S3 的色相＋飽和×256 |
| 23 取色③ 色相＋飽和＋明度 | 原始 RGB 同上，反射光為 S1 明度 |
| 30 依序取色號 | 顏色＝總塊數，原始 RGB 每格裝兩塊色相 |
| 41–43 黑線／白線／色線 | 顏色＝路口，反射光＝近線寬，原始 RGB＝近偏移、遠偏移、角度各＋100 |
| 51 物體清單 | 積木讀前 3 個，Python 有後續欄位 |
| 52 物體詳細 | 積木讀物體 1 的位置／寬高，另有物體 2 的代碼與面積 |

以 256 打包的欄位，先把原始值轉為無號 16 位元（負值加 65536），再取餘數與整除。色相 0 可以代表紅色，判斷色序時請搭配總塊數。循線的原始 RGB 各減 100；例：原始紅 80 表示近處偏移 −20。

### ✔ SPIKE App Python 額外欄位

device.data(port.C) 的前兩個元素是 byte 0、1，後面每個元素各含兩個 byte，先取低位再取高位。共可讀 byte 0–13；相機送出的 byte 14、15 無法透過這個 API 取得。

```python
from hub import port
import device

values = device.data(port.C)
data = [value & 255 for value in values[:2]]
for word in values[2:]:
    data.extend((word & 255, (word >> 8) & 255))
```

| 相機模式 | 可讀取的額外 byte |
| --- | --- |
| 11 | 8–13：色 8–13 的位置（8×6 格） |
| 12 | 8–13：色 1–6 的數量 |
| 13 | 8–11：色 1–4 數量；12–13：色 1–2 面積 |
| 14 | 8–9：色 1–2 數量；10–11：色 1–2 面積 |
| 21 | 8–13：S7–S12 色相 |
| 22 | 8：S4 色相；9–12：S5、S6 的 H、S；13：S7 色相 |
| 23 | 8–9：S2、S3 明度；10–12：S4 的 H、S、V |
| 30 | 8–13：左起第 7–12 塊色相 |
| 41–43 | 8–13：中偏移＋100、旗標、路口距離、標記色號、標記累計、遠線寬 |
| 51 | 8–13：物體 4–6 的代碼、位置 |
| 52 | 8：物體 1 角度；9–13：物體 2 X、Y、寬、高、角度 |

## 03 / 範例程式

### ✔ 讀取色 2 的位置

1. 將兩種顏色分別教成目標色 1 與 2。先確認即時畫面能找到色 2。
2. 在重複迴圈中讀取一次「原始紅」，存成變數，再用上表換算 X、Y。
3. 顯示 X、Y。左右移動色 2，觀察 X 是否跟著改變。移出畫面時，確認 X 回到 0。
