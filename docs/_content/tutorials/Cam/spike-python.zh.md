## 01 / 環境準備

### ✔ 請確認控制器、感應器與程式環境

| 要求 | 符合本教學頁面的種類 |
| --- | --- |
| 控制器 | LEGO® Education SPIKE™ Prime Set<br>LEGO® MINDSTORMS® Robot Inventor |
| 感應器 | MBC 神攝手視覺感應器 (SPIKE 版) |
| 程式語言 | Pybricks Python |

### ✔ 事前準備

1. 啟動你的機器人與 Pybricks Python。
2. 確認主機已安裝 Pybricks 韌體，且相機與主機連線正常。
3. 設定感應器模式，確認與程式設定模式相同。

## 02 / 函數與功能說明

::: info ℹ️ 補充資訊
- 本教學使用 `PUPDevice(Port.C)`。相機模式由機身選單設定，主要資料使用通訊模式 9；模式 11、12 的數量資料使用通訊模式 6。
- 表格中的 `data = read_payload()` 是模式 9 拆出的 14 個 byte；`counts = read_payload(6)` 是模式 6 拆出的 6 個 byte。每個 int16 先取低位，再取高位，索引從 0 開始。
- 「讀取數值」指第一欄指令的回傳結果。`signed_byte()` 處理有號 byte，`count_mode11()` 處理模式 11 的數量；完整函式集中在第 03 節，不需額外安裝函式庫。
- 表中的「 ÷ 」表示整數除法，需捨去小數；「mod」表示取餘數。先讀取一次資料並存入變數，再依表格解碼。
- 面積、飽和度、明度、線寬與路口距離以百分比表示，數值範圍不另外加百分號。
:::

::: warning ⚠️ 注意
- 一次只能使用一種相機子模式，請確認相機 Mode ID 與程式設定相同。
- 不同模式共用相同讀取指令，回傳內容須依該模式的表格解碼。
:::

## 03 / 範例程式

### ✔ 讀取顏色 1 的位置、面積與數量

1. 將相機接到 C 埠，教好目標色 1，並在相機選單選擇 Mode ID 13 (顏色追蹤 - ③ 標準)。
2. 執行下方完整程式，每輪以 `read_payload()` 取得一次資料，再讀取 `data[0]`、`data[1]`、`data[2]` 與 `data[12]`。
3. 移動目標，確認 X 向右增加、Y 向下增加；移出畫面時顯示「No target」。

```python
from pybricks.iodevices import PUPDevice
from pybricks.parameters import Port
from pybricks.tools import wait

cam = PUPDevice(Port.C)


def read_payload(read_mode=9):
    words = cam.read(read_mode)
    if read_mode == 6:
        wait(30)
        words = cam.read(read_mode)
    payload = []
    for word in words:
        payload.extend((word & 255, (word >> 8) & 255))
    return payload


def signed_byte(value):
    return value - 256 if value >= 128 else value


def count_mode11(counts, color):
    if not 0 <= color <= 14:
        raise ValueError("Color index must be 0 ~ 14")
    offset = 3 * (color - 1) if color else 42
    index, shift = divmod(offset, 8)
    pair = counts[index]
    if index + 1 < len(counts):
        pair |= counts[index + 1] << 8
    return (pair >> shift) & (7 if color else 15)


while True:
    data = read_payload()
    if data[0]:
        x, y, area = data[0], data[1], data[2]
        count = data[12] // 16
        print("Color 1:", x, y, "Area:", area, "Count:", count)
    else:
        print("No target")
    wait(100)
```

### ✔ 模式 11：讀取位置與數量

先在相機選 Mode ID 11。保留上方的匯入、相機宣告與三個函式，只把最後的 `while True` 區塊替換為以下內容。數量的位元解碼每次最多組合兩個 byte，避免超過主機的整數容量。

```python
while True:
    data = read_payload()
    counts = read_payload(6)
    print("Colors found:", count_mode11(counts, 0))
    for color in range(1, 15):
        grid_id = data[color - 1]
        if grid_id == 0:
            continue
        x = (grid_id - 1) % 16 + 1
        y = (grid_id - 1) // 16 + 1
        print(color, x, y, count_mode11(counts, color))
    wait(100)
```

### ✔ 循線模式：讀取偏移與角度

先在相機選 Mode ID 41、42 或 43。保留相同匯入、相機宣告與函式，只替換最後的迴圈。偏移與角度依 GitHub 的有號 byte 格式處理，不加 100。

```python
while True:
    data = read_payload()
    near = signed_byte(data[0])
    far = signed_byte(data[2])
    angle = signed_byte(data[3])
    junction = data[6]
    print(near, far, angle, junction)
    wait(100)
```
