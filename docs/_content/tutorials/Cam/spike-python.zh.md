# 使用教學

## 01 / 環境準備

### ✔ 請確認控制器、感應器與程式環境

| 要求 | 符合本教學頁面的種類 |
| --- | --- |
| 控制器 | LEGO® Education SPIKE™ Prime Set<br>LEGO® MINDSTORMS® Robot Inventor |
| 感應器 | MBC 神攝手視覺感應器 (SPIKE 版) |
| 程式語言 | Pybricks Python |

### ✔ 事前準備

1. 啟動你的機器人與 Pybricks Python。
2. 確認主機已安裝 Pybricks 韌體，且相機與主機連線正常。
3. 設定感應器模式，確認與程式設定模式相同。

## 02 / 基礎控制-前置作業與函數功能說明

### ✔ 前置作業

1. 不需匯入外加函式庫。將相機接到 C 埠，使用 Pybricks 內建顏色感應器。
2. 在相機機身選單選擇 Mode ID，讓讀值表與相機模式一致。
3. 匯入 `ColorSensor`，建立 `cam = ColorSensor(Port.C)`，使用 `cam.reflection()` 與 `cam.ambient()`。

::: info ℹ️ 補充資訊
- 使用內建顏色感應器，將反射光與環境光讀值存入變數，再依目前相機模式拆解。相機模式由機身切換。
- 表中的「 // 」表示整數除法，「mod」表示取餘數。環境光只保留小數第一位：整數部分無條件捨去小數，小數位用 round(讀值 × 10) % 10 取得。
:::

::: warning ⚠️ 注意
- 一次只能使用一種相機子模式，請確認相機 Mode ID 與程式設定相同。
- 不同模式共用相同讀取指令，回傳內容須依該模式的表格解碼。
:::

#### 模式二：指定座標取色

#### 模式五：物體偵測

<CamModeSection mode="51" title="物體偵測 - ① 物體清單">

### ✔ 基礎控制範例

在相機選單選擇 Mode ID 13，教好目標色 1、2，再執行下方程式。顏色 1 使用 40 × 30 格，顏色 2 使用 8 × 6 格；任一顏色的 X 為 0 表示未找到。

```python
from pybricks.pupdevices import ColorSensor
from pybricks.parameters import Port
from pybricks.tools import wait
from math import floor

cam = ColorSensor(Port.C)

while True:
    reflected = cam.reflection()
    ambient = cam.ambient()
    if reflected < 0:
        reflected += 6399
    x1 = reflected // 100
    y1 = reflected % 100
    x2 = floor(ambient)
    y2 = round(ambient * 10) % 10
    print("Color 1:", x1, y1, "Color 2:", x2, y2)
    wait(100)
```

例如 reflected = 2015、ambient = 4.3，會得到顏色 1 的分格位置 (20, 15)、顏色 2 的分格位置 (4, 3)。

## 03 / 進階控制-前置作業與函數功能說明

### ✔ 前置作業

<DownloadButton href="/programs/Cam/spike-pybricks/MBC_UniCam.py" download="MBC_UniCam.py" label="MBC_UniCam.py" />

1. 下載 `MBC_UniCam.py`，匯入 Pybricks，檔名保持不變，並與主程式放在同一個工作區。
2. 將相機接到 C 埠，匯入 `UniCam`，建立 `cam = UniCam(Port.C, mode=13)`。建立物件時會切換相機模式，其他模式可用 `cam.set_mode(Mode ID)` 切換。
3. 使用下方函式取得已解碼資料，不需自行讀取 byte 或建立數值解碼函式。

::: info ℹ️ 補充資訊
- 函式庫以通訊模式 9 讀取主要資料；模式 11、12 的數量會改讀通訊模式 6。換讀取模式需要等待，數量只在需要時查詢。
- 一次只啟用一種相機子模式，程式與相機的 Mode ID 必須相同。函式庫已處理打包、座標換算與循線有號數，不需額外加 65536。
- 座標以像素表示，X 向右、Y 向下增加。模式 11 的 `cell` 另提供 16 × 12 分格位置；像素位置取分格中心，精度不等於逐像素偵測。
- 尚未成功讀到資料時可能回傳 `None`；斷線後可能保留上一次讀值。先檢查連線狀態，再使用結果。
- `cam.sensor_ok()` 回傳連線狀態。表格中的配對結果取值，例如 `cam.size(1)[0]`，使用前先確認整組結果不是 `None`；同組資料建議先存入變數再取值。
:::

### ✔ 進階控制範例

教好目標色 1 後執行下方完整程式。此例使用模式 13，位置、面積與數量都由函式庫處理。

```python
from pybricks.parameters import Port
from pybricks.tools import wait
from MBC_UniCam import UniCam

cam = UniCam(Port.C, mode=13)

while True:
    position = cam.xy(1)
    if not cam.sensor_ok() or position is None:
        print("Camera not connected")
    elif position == (0, 0):
        print("No target")
    else:
        print("Color 1:", position, "Area:", cam.area(1), "Count:", cam.count(1))
    wait(100)
```

### ✔ 模式切換與其他讀值

以下片段分別替換主程式的讀值流程，不要把不同模式的讀值混在同一輪。模式只需在進入對應迴圈前切換。

```python
cam.set_mode(11)
position = cam.xy(1)
cell = cam.cell(1)
count = cam.count(1)
print(position, cell, count)

cam.set_mode(23)
print(cam.hsv(1))

cam.set_mode(41)
print(cam.near(), cam.far(), cam.angle(), cam.junction())

cam.set_mode(52)
if cam.object_found(1):
    print(cam.object(1), cam.object_xy(1), cam.object_size(1), cam.object_area(1))
```

### ✔ 函式庫控制與狀態

| 指令 | 用途 |
| --- | --- |
| `cam.set_mode(13)` | 切換到指定 Mode ID。 |
| `cam.sensor_ok()` | 檢查最近一次讀取是否成功。 |
| `cam.mode_number()` | 取得程式設定的 Mode ID。 |
| `cam.device_id()` | 取得裝置位址、硬體代碼與韌體版本字。 |
| `cam.is_unicam()` | 檢查是否為神攝手。 |
| `cam.firmware_version()` | 取得 (主版, 次版)。 |
| `cam.max_color() / cam.max_point() / cam.max_object()` | 依目前模式取得可讀顏色、取樣點或物體數量上限。 |
| `cam.light(50)` | 補光亮度 0 ~ 100；light(None) 回到相機選單設定。 |
| `cam.teach(1) / cam.clear(1)` | 用畫面中央教目標色，或清除指定目標，編號 1 ~ 16。 |
| `cam.target_range(1, hue=20, sat=10, size=10, search=2)` | 調整已教目標的色相容許、飽和容許、最小面積與搜尋方式；255 = 保留，search 0 = 保留、1 = 鎖定、2 = 最大塊。Hue 1 ~ 119、Sta 0 ~ 31、Size 4 ~ 254。 |
| `cam.shape_tolerance(3) / cam.target_shape(1, 3)` | 形狀寬鬆度 1 ~ 5；目標 1 ~ 8 的指定形狀 0 ~ 9，0 = 不指定。 |
| `cam.camera_setting(item, value)` | Setup 項目 0 ~ 12，順序與相機選單相同，設定值可為負數。 |
| `cam.white_cal()` | 白紙先覆蓋畫面中央，再執行白色校正。 |
| `cam.power(0)` | 0 = 全速、1 = 省電、2 = 待機；待機喚醒需要 1 ~ 2.5 秒。 |
| `cam.cmd(code, *parameters) / cam.busy() / cam.wait_done()` | 傳送自訂命令、查忙碌狀態與等待完成。不要在讀值迴圈頻繁查命令狀態。 |

控制命令的完成狀態：0 = 完成、2 = 失敗、3 = 拒絕、`None` = 未取得完成結果。`cmd()` 回傳序號，`busy()` 回傳布林值。
